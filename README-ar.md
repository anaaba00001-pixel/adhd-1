# نشر دليل ADHD على Cloudflare Workers عبر GitHub

## تجهيز قاعدة البيانات

1. افتحي Cloudflare ثم D1 SQL Database. أنشئي قاعدة باسم `adhd-guide-db`.
2. داخل Console الصقي محتوى `adhd-worker/schema.sql` واضغطي Execute.
3. انسخي Database ID. في `adhd-worker/wrangler.jsonc` استبدلي `REPLACE_WITH_D1_DATABASE_ID` بالمعرّف واتركي علامتي الاقتباس.

## نشر الموقع

1. أنشئي مستودع GitHub جديدًا للدليل. ارفعي مجلد `adhd-worker` كاملًا إلى جذر المستودع على فرع `main`.
2. أنشئي مشروع Cloudflare **Worker** باسم `adhd-guide` واربطيه بمستودع الدليل. إذا اخترتِ اسم Worker آخر، اجعليه مطابقًا لحقل `name` في `wrangler.jsonc`.
3. في إعدادات Builds، اختاري `main` لفرع الإنتاج و`/` في Root directory. اتركي Build command فارغًا. ضعي هذا في Deploy command:

   ```bash
   npx wrangler deploy --config adhd-worker/wrangler.jsonc
   ```

4. بعد نجاح النشر افتحي رابط Production من Domains. يفتح الدليل مباشرة. سجّلي تمرينًا وملاحظة وانتظري رسالة «حُفظ التقدم في قاعدة البيانات».
5. اضغطي «رابط المزامنة الخاص»، وافتحي الرابط على الجهاز الثاني. تأكدي من ظهور التقدم نفسه. احتفظي بالرابط في مكان خاص. كل من يملك الرابط يستطيع قراءة السجل وتعديله. إذا مسحتِ بيانات المتصفح، افتحي الرابط الخاص مرة أخرى لاستعادة الاتصال بسجلك.

إذا كنتِ تستبدلين الإصدار السابق الذي يطلب كلمة مرور، صدّري تقدمك منه أولًا إن كان فيه بيانات. أعيدي تنفيذ schema.sql داخل نفس قاعدة الدليل لإنشاء جدول النسخة الجديدة، ثم حدّثي الملفات في GitHub واستوردي النسخة بعد النشر. يبقى الجدول القديم موجودًا في D1. الإصدار الجديد ينشئ سجلًا منفصلًا لكل متصفح، ويمكن مشاركة السجل بين أجهزتك بالرابط الخاص.

عند تعارض تعديلين، صدّري نسختك قبل تحميل السجل السحابي ثم استورديها. يجمع الاستيراد الإنجاز وسجلات الدفتر ويحتفظ بنص الملاحظة السحابية إذا وجدت ملاحظة أخرى بالمفتاح نفسه.

## نسخ تقدم النسخة القديمة

إذا كنتِ تستخدمين الملف القديم، افتحيه في نفس المتصفح وبنفس المسار أو الرابط الذي حفظتِ منه التقدم. في Chrome أو Edge اضغطي F12 ثم Console وشغّلي الكود أدناه إذا كنتِ مرتاحة لاستخدام أدوات المطوّر. يقرأ الكود سجل الدليل في ذلك المتصفح وينزله في ملف محلي.

```js
(() => {
    const raw = localStorage.getItem("adhd-v1");
    if (!raw) {
        alert("لا يوجد تقدم محفوظ لهذا الدليل في الصفحة الحالية.");
        return;
    }
    const url = URL.createObjectURL(new Blob([raw], { type: "application/json" }));
    const link = document.createElement("a");
    link.href = url;
    link.download = "adhd-progress.json";
    link.click();
    setTimeout(() => URL.revokeObjectURL(url), 1000);
})();
```

في الموقع المنشور اختاري «استيراد نسخة» وأضيفي الملف الناتج. احتفظي بالملف لمراجعة أي ملاحظات متعارضة. محتوى «استخلاص» والاقتراحات في الملف الأصلي يعتمد على مكوّن Claude الخاص بالبيئة الأصلية. اتصال D1 يحفظ سجل التدريب فقط، لذلك تظل وظائف Claude غير متاحة على الاستضافة المستقلة.
